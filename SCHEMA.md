Generated from `src/server/notion/schema.ts` — the single source of truth the provision script writes to Notion. Do not edit this file by hand; change the schema and re-run `npm run schema:doc`.

Generated 2026-07-31 · 17 databases

## How to read this

- **Notion is the system of record.** The app is a front end over a local cache with an explicit refresh — never a second database.
- **Key** is the internal handle used in code (`cachedRecords("designs")`); **Title** is the database name in Notion. Field names below are the exact Notion property names.
- Select options listed here are **pre-seeded**. Notion accepts new options on write, so a live database may hold more than this lists.
- Provisioning is idempotent: re-running it patches missing properties onto existing databases and never creates duplicates. Adding a field here means running **Sync schema** once after deploy.
- Every synced record carries its external IDs — that rule is not optional.
